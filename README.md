## 연구실 소개

대전대학교 DJU ADAS Lab입니다. 차량 데이터 계측과 분석, 차량 통신, 임베디드 시스템을 주제로 연구와 개발을 진행합니다.

이곳에서는 연구 과정에서 개발한 소프트웨어와 실험에 사용한 도구를 정리합니다. 프로젝트별 소개와 사용 방법은 각 저장소에서 확인할 수 있습니다.
